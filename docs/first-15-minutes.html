The first 15 minutes

This is the parent-evaluation path. It is short on purpose: install, create profiles, run one quiz, generate one worksheet, and confirm the backup story.

Minute-by-minute path

  1. Minute 0-3: open the app and create one parent profile and one child profile.
  2. Minute 3-5: set the parent PIN and confirm the Parent tab is protected.
  3. Minute 5-8: start one focused quiz for a known topic and use the intuition prompt once.
  4. Minute 8-11: open the Parent area and generate one worksheet.
  5. Minute 11-13: review the Dashboard to confirm progress and assignment surfaces make sense.
  6. Minute 13-15: read the local backup path and verify where data is stored on the machine.

What should feel clear

  • The app is math-first, not just a fractal demo.
  • The child flow is calm and direct.
  • The parent tools feel useful without a long learning curve.
  • The local/offline story is understandable.

What should raise a beta flag

  • Install friction or unclear first launch steps
  • Confusion about which topics are actually covered
  • Unclear worksheet output or answer key layout
  • Uncertainty about where student data is stored

Recommended parent evaluation questions

  • Would I trust this on my child’s laptop?
  • Could I run this without internet during a school day?
  • Would the worksheet and quiz flow save me time?
  • Is the topic coverage honest enough for how I teach?
