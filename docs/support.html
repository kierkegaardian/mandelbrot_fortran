Support and backup guide

Current support is optimized for beta and early family launch. Use the guide below before opening an issue so reports come in with the right context.

Open a support issue Read local setup docs

Before opening an issue

  • Confirm which platform you are on.
  • Note whether this is a development run or packaged app.
  • Capture the exact step where the app stopped behaving as expected.
  • If saved data is involved, back up the data directory first.

Current support intake

  • Bug reports: GitHub issue template
  • Beta reactions: GitHub beta-feedback template
  • Release notes: GitHub releases and repo docs

A dedicated family-support email is still an external launch dependency and should be added before broader paid outreach.

Most common help paths

Install and first launch

If the packaged app does not launch, note the platform, the bundle name, and whether the failure happens before profile selection.

Quiz or worksheet issues

Report the skill, selected subskill if any, and whether the issue happened in intuition, expression, or word mode.

Parent controls

Include whether the issue is about profile creation, parent PIN, assignments, offline-mode settings, or the operator-configured Family Sync beta.

Family Sync beta support boundary

Public v1 builds do not include or select a hosted sync server. Local-only is the default, and the beta controls remain disabled unless an operator supplies a compatible server through MANDELQUEST_SYNC_CONFIG and a parent opts in.

If beta sync fails, keep using the local app, do not repeatedly relink the family, and back up the data directory before troubleshooting. Report the platform, server label, last sync message, and whether local changes are shown as queued. Do not post pairing codes or learner data in a public issue.

Backup steps

  1. Close MandelQuest fully.
  2. Copy the full local data directory for your platform.
  3. Prioritize app.db, ui_settings.json, and worksheets/.
  4. When reporting an issue, keep the original backup untouched.
Important: If support involves missing progress or worksheets, do not keep launching and retrying before you make a backup copy.

Known limitations to mention up front

  • No hosted cloud/LAN sync service ships with v1; the operator-configured Family Sync beta is experimental and disabled by default.
  • Desktop app first; no browser-first workflow for families or adult learners yet.
  • Geometry proofs, full Algebra 2 depth, and broad college placement prep are not complete.
  • Some PDF conversion helpers depend on optional system tools such as pdftotext.
