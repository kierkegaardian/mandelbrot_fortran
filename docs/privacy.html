Privacy and local-data policy

MandelQuest is designed around local-first family use. Core learning flows do not require an account, cloud sync, or always-on internet access.

What the app stores locally

  • Profiles and parent-role information
  • Parent PIN settings and lockout state
  • Quiz attempts, question history, and progress
  • Assignments and worksheet records
  • UI settings such as offline mode and accessibility presets

What the app does not require

  • No login account for core use
  • No required cloud sync
  • No always-on outbound network connection
  • No ads or ad-tracking workflow in core learning paths

Family Sync (Beta)

Family Sync is an experimental, operator-configured beta. It is off by default, public builds include no sync server, and a parent cannot enable it unless the install has a machine-local configuration for a compatible server. Core learning remains available in local-only mode.

Sent after opt-in: profile names and roles; quiz sets; assignments and notes; completed quiz attempt scores and timing; full question history including prompts, correct answers, learner answers, correctness, and explanations; plus sync identifiers, timestamps, and deletion markers.
Kept on this device: parent PIN and lockout data; UI and offline settings; local PDFs; worksheet files and records; Summer Program state; school-year targets; derived progress tables; and in-progress quiz resume state.

The family or operator running the configured beta server is responsible for that server's access, retention, backups, and deletion policy. Back up local data before testing sync.

Where data lives

Environment Default data location What is stored there
Development run data/ in the repository app.db, ui_settings.json, generated worksheets, cached support files
Windows packaged app %APPDATA%\MandelQuest Same local database and worksheet outputs
macOS packaged app ~/Library/Application Support/MandelQuest Same local database and worksheet outputs
Linux packaged app ${XDG_DATA_HOME:-~/.local/share}/MandelQuest Same local database and worksheet outputs

Advanced testing or managed installs can override the data path with MANDELQUEST_DATA_DIR.

Optional internet-linked actions

External lesson links can open Khan Academy pages in a browser, but these links are optional and disabled by default.

Parents can also enforce offline mode, which disables those web launches entirely.

Historical PDF tools

SAT, PSAT, GRE, and curriculum PDF features read local PDF files already on the machine. They do not require cloud processing.

Backup and deletion

Backup: close the app, then copy the local data directory, especially app.db and worksheets/, to another location.
Delete local data: remove the MandelQuest data directory for your platform. This removes local profiles, progress, settings, and worksheet records stored by the app.

Beta feedback and testimonials

Written testimonials or recorded beta reactions are always opt-in. If public quotes are requested, ask for clear permission before reuse.
