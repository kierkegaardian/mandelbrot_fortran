# 90-Second Demo Script

## Goal
Show homeschool parents that MandelQuest is a calm, local-first math practice app with useful parent tools.

## Script
1. Open on the profile picker.
   - Voiceover: `MandelQuest is an offline-first desktop math practice app built for homeschool families.`
2. Show child profile entering the Dashboard.
   - Voiceover: `A learner can jump straight into review, see progress, and start a daily quiz without needing an account.`
3. Start one focused quiz and trigger an intuition hint.
   - Voiceover: `The practice flow is built around intuition, expression work, and clear feedback instead of noisy game mechanics.`
4. Switch to Parent tools and show the PIN gate.
   - Voiceover: `Parents keep control with protected settings, profiles, assignments, and quiz sets.`
5. Generate one worksheet and show the answer key.
   - Voiceover: `When you need printable practice, worksheets are created locally and stored with the rest of your family data.`
6. End on the support/privacy pages.
   - Voiceover: `The app is local-first, backup-friendly, and honest about what it covers today.`

## Production rules
- Keep it under 90 seconds.
- Use one real student path and one real parent path.
- Avoid feature dumping.
- End with the homeschool-first positioning sentence.
